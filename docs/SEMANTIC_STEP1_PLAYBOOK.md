Generated by the `semantic-in-browser-discovery` workflow (run `wf_f17b52b0-276`). Step 1 of the implementation order in [SEMANTIC_SEARCH.md](SEMANTIC_SEARCH.md): "Wire offscreen doc + transformers.js, prove single-embed round-trip with a hardcoded string."

## Acceptance test

A single round-trip from the **background service worker devtools console** that proves the offscreen doc + transformers.js pipeline is wired end-to-end:

1. Build & load the extension (see "Build & run sequence").
2. Open `chrome://extensions`, click the Better Bookmarks **service worker** link → DevTools opens on the background page.
3. Paste into that console and press Enter:
   ```js
   await chrome.runtime.sendMessage({ type: 'semantic:embed', text: 'hello world' })
   ```
4. Expected on cold start (model not yet cached): a single response within **30 seconds** on broadband, shape:
   ```js
   { ok: true, model: 'Xenova/bge-small-en-v1.5', dim: 384, vector: Array(384), backend: 'webgpu' | 'wasm' }
   ```
   On a warm start (Cache API hit) the response should arrive in under **2 seconds**.
5. A second call with the same text returns a vector whose first three values match the first call to >=5 decimal places (determinism check).
6. In the offscreen doc's console (chrome://extensions → "Inspect views: offscreen.html"), confirm exactly one line `[semantic] backend=<webgpu|wasm> model=Xenova/bge-small-en-v1.5 dim=384` was logged.

No Dexie row written, no UI affected, no bookmarks touched. Pure infra round-trip.

### `src/entrypoints/offscreen/main.ts`

```ts
import { embed, warmup } from "@/core/semantic/model";

void warmup();

chrome.runtime.onMessage.addListener((msg, _sender, sendResponse) => {
  if (msg?.type !== "semantic:embed") return false;
  (async () => {
    try {
      const { vector, model, dim, backend } = await embed(String(msg.text ?? ""));
      sendResponse({ ok: true, vector: Array.from(vector), model, dim, backend });
    } catch (err) {
      sendResponse({ ok: false, error: String(err) });
    }
  })();
  return true;
});
```

### `src/core/semantic/model.ts`

```ts
import { env, pipeline, type FeatureExtractionPipeline } from "@huggingface/transformers";

export const DEFAULT_MODEL = "Xenova/bge-small-en-v1.5";

let pipe: FeatureExtractionPipeline | null = null;
let chosenBackend: "webgpu" | "wasm" = "wasm";

function configureEnv(): void {
  env.allowLocalModels = false;
  env.allowRemoteModels = true;
  env.useBrowserCache = true;
  env.backends.onnx.wasm.wasmPaths = chrome.runtime.getURL("transformers/");
  env.backends.onnx.wasm.numThreads = 1;
}

export async function warmup(): Promise<void> { await getPipeline(); }

async function getPipeline(): Promise<FeatureExtractionPipeline> {
  if (pipe) return pipe;
  configureEnv();
  const wantsGPU = typeof (navigator as { gpu?: unknown }).gpu !== "undefined";
  try {
    pipe = await pipeline("feature-extraction", DEFAULT_MODEL,
      { device: wantsGPU ? "webgpu" : "wasm", dtype: "fp32" });
    chosenBackend = wantsGPU ? "webgpu" : "wasm";
  } catch (err) {
    console.warn("[semantic] webgpu init failed, falling back to wasm", err);
    pipe = await pipeline("feature-extraction", DEFAULT_MODEL, { device: "wasm", dtype: "fp32" });
    chosenBackend = "wasm";
  }
  console.log(`[semantic] backend=${chosenBackend} model=${DEFAULT_MODEL} dim=384`);
  return pipe;
}

export async function embed(text: string): Promise<{ vector: Float32Array; model: string; dim: number; backend: "webgpu" | "wasm" }> {
  const p = await getPipeline();
  const t = await p(text, { pooling: "mean", normalize: true });
  return { vector: t.data as Float32Array, model: DEFAULT_MODEL, dim: t.data.length, backend: chosenBackend };
}
```

### `src/core/semantic/bridge.ts`

```ts
const OFFSCREEN_URL = "offscreen.html";

export async function ensureOffscreen(): Promise<void> {
  if (await chrome.offscreen.hasDocument()) return;
  await chrome.offscreen.createDocument({
    url: OFFSCREEN_URL,
    reasons: ["WORKERS" as chrome.offscreen.Reason],
    justification: "Run transformers.js for semantic search embeddings (WebGPU/WASM).",
  });
}

export async function embedViaOffscreen(text: string) {
  await ensureOffscreen();
  return chrome.runtime.sendMessage({ type: "semantic:embed", text });
}
```

### `modules/copy-onnx-wasm.ts`

```ts
import { defineWxtModule } from "wxt/modules";
import { existsSync, mkdirSync, copyFileSync, readdirSync } from "node:fs";
import { join, dirname } from "node:path";
import { createRequire } from "node:module";

export default defineWxtModule({
  name: "copy-onnx-wasm",
  setup(wxt) {
    wxt.hooks.hook("build:before", () => {
      const require = createRequire(import.meta.url);
      const pkgPath = require.resolve("@huggingface/transformers/package.json");
      const distDir = join(dirname(pkgPath), "dist");
      const outDir = join(wxt.config.root, "public", "transformers");
      if (!existsSync(outDir)) mkdirSync(outDir, { recursive: true });
      for (const f of readdirSync(distDir)) {
        if (/\.(wasm|mjs)$/.test(f)) copyFileSync(join(distDir, f), join(outDir, f));
      }
    });
  },
});
```

## Known unknowns / risks

1. **WXT may not auto-route `src/entrypoints/offscreen.html`.** Fallback: move to `src/entrypoints/offscreen/index.html`, keep `bridge.ts` URL as `"offscreen.html"` (WXT flattens nested HTML entrypoints).

2. **`'wasm-unsafe-eval'` CSP key may be rejected by older Chromium.** Confirmed correct for MV3 on Chrome 138+.

3. **ORT dynamic `import()` of `ort-wasm-simd-threaded.jsep.mjs` may 404.** Verify `public/transformers/` contents after build; package layout may have shifted in v4.x.

4. **SW → offscreen messages may race the offscreen doc's listener registration.** Either retry once or have offscreen ping back a `ready` message before `bridge.ts` returns.

5. **WebGPU may be unavailable in some Chrome channels.** `model.ts` already wraps in try/catch and falls back to WASM. Acceptance test should treat `backend: 'wasm'` as a pass.

6. **`@types/chrome` may type `chrome.offscreen.Reason` missing `"WORKERS"`.** Cast handles it; escalate to `as unknown as chrome.offscreen.Reason` if needed.

7. **Model download (~33 MB) may time out behind corporate proxies / VPNs.** Check Network tab in offscreen DevTools.
